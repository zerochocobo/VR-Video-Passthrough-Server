# Handover — 2026-07-19

## RTX VSR progress

- RTX VSR assets remain under `models/rtx_vsr/native` and `models/rtx_vsr/runtime`.
- Python calls the precompiled native bridge through `ctypes`; no official NVIDIA Python binding exists.
- `models/rtx_vsr/native/build.ps1` now defaults to CUDA 12.6, the validated CUDA 12.x build line.
- VSR quality configuration now follows the SDK enum completely: `0=Bicubic`, `1=Low`, `2=Medium`, `3=High`, `4=Ultra`.
- Added `RTX_VSR_EVALUATE_TIMEOUT_SEC` (default 45 seconds).
- Added isolated child-process evaluation preflight in `utils/rtx_vsr.py` and frozen-app tool dispatch in `main.py`.
- Realtime SuperRes now refuses requests when the real NGX evaluation preflight fails or times out, preventing a media worker from hanging indefinitely.
- Offline SuperRes now performs the same isolated preflight before creating FFmpeg pipes, so known SDK/driver failures do not leave partial output files.

## DLNA SuperRes empty-directory fix

- Root cause: SuperRes containers were emitted with `plsr_...` IDs, but `_id_to_live()` had no `plsr_`/`plsr_item_` parser branch, so BrowseDirectChildren treated them as unknown and returned zero children.
- Added dedicated SuperRes live, live-item, and seek ID constants/parsers plus consistent 2D/resolution gating for chapter and time-index browsing.
- Bumped DIDL schema/object IDs from `ptv10` to `ptv11` so DLNA clients discard cached empty containers after server restart.
- Regression set: 63 passed, 5 subtests passed.
- UI correction: removed the redundant Offline SuperRes button from the server bar. Offline SuperRes remains available from Tools; the dashboard retains only the realtime SuperRes switch.

## Realtime SuperRes image-corruption fix

- User symptom: gray dropped-looking frames with locally repeated/tiled image regions; offline VSR was correct.
- Root cause: NGX returns contiguous RGBA8 (4-byte pixel stride), but realtime passed the non-contiguous `sr_out[:, :, :3]` view to a kernel that assumed tightly packed RGB (3-byte stride).
- Added a dedicated `rgba_to_nv12` CUDA kernel and pass the original contiguous RGBA output directly.
- Full PyNv realtime test after the fix: 5 frames, 35 MPEG-TS chunks, 148520 bytes, HEVC 1280x720 + AAC, no startup error; decoded first frame was visually correct without gray tiling/repetition.
- Regression set: 48 passed, 5 subtests passed.
