# 2026-10-08 DA3-SMALL ONNX 导出

## 需求与实现

- 用户要求使用 `examples/da3_to_onnx.py` 从官方 https://huggingface.co/depth-anything/DA3-SMALL/tree/main 生成 Small 模型。
- 原脚本的 Toolbox DA3 源码和权重路径已不存在；本仓库已有 `reference/da3/src/depth_anything_3`，可复用 Toolbox Python 环境，不需安装依赖。
- 脚本改为直接调用 upstream backbone 和 depth head，消除对旧 vendor 私有 `skip_camera/skip_sky` 参数的依赖。加载时使用官方同一 preset 和 safetensors 严格权重匹配，避免引入场景导出、姿态对齐等非必要 API 依赖。
- `--vendor` 支持官方 checkout 与旧 source-root 布局；默认优先本项目 `reference/da3`。权重默认放在本项目 `models/DA3/{Small,Base,Large}`。
- 新增 `--download`、`--revision`，只下载所选官方仓库的 `config.json` 和 `model.safetensors`；校验 config 中的 variant，避免用错模型。
- 修复文档中的 `--validate` 原本没有 argparse 定义的问题；增加 ONNX checker 和非有限输出检查，超出误差阈值时以失败退出。尺寸必须为正的 14 倍数。
- 更新 `examples/da3_README.md` 导出命令、依赖、来源和输入输出格式；`.gitignore` 忽略原始权重目录。
