# HANDOVER 2026-09-12

## DLSS 5 Neural Rendering (NR) 集成完成记录

### 背景

参考开源项目 [`Merserk/dlss5-visual-enhancer`](https://github.com/Merserk/dlss5-visual-enhancer)
（源码位于 `reference/dlss5-visual-enhancer-main`），将 DLSS 5 Neural Rendering
的调用链集成到本项目中，运行时位于 `models/dlss5/runtime/`。

### 核心新增与修改模块

1. **[models/dlss5/neural_bridge.py](../models/dlss5/neural_bridge.py)**：
   - 封装 Neural Rendering 运行时的 ctypes 绑定，支持 ABI v6。
   - 提供 `BRIDGE.initialize()`、`BRIDGE.process_host()`、`BRIDGE.process_cuda_pointers()`。
2. **[utils/dlss5.py](../utils/dlss5.py)**：
   - `DLSS5Settings` 参数类（style、intensity、local_tone、local_structure、
     skin_structure、auto_mask、grain_preservation、nr_passes 等）。
   - 运行时可用性检测与输入尺寸校验函数。
3. **[pipeline/dlss5_stage.py](../pipeline/dlss5_stage.py)**：
   - 全程 GPU 驻留的 NV12 ↔ Float32 RGB CUDA Kernel 与 DLSS 5 NR 特征评估流水线阶段。
4. **[offline/dlss5_offline.py](../offline/dlss5_offline.py)**：
   - 独立的离线视频转码引擎，支持单文件/批量处理与进度输出。
5. **[offline/convert.py](../offline/convert.py)**：
   - 注册 `--engine dlss5`，自动匹配 `[DLSS5]` 输出命名，支持各项 DLSS 5 渲染参数命令行调整。
6. **[utils/vr_naming.py](../utils/vr_naming.py)**：
   - 增加 `DLSS5_PREFIX = "[DLSS5]"` 与 `dlss5_output_stem` 命名规范。
7. **[config.py](../config.py)**：
   - 增加 DLSS 5 全局配置项（`DLSS5_ENABLED`、`DLSS5_STYLE`、`DLSS5_INTENSITY` 等）。

### 实测验证

在本地 NVIDIA GeForce RTX 5060 Ti 上：
- Neural Rendering 运行时初始化成功。
- `DLSS5Stage` 跑通 GPU 驻留的 NV12 → Float32 RGB → DLSS 5 NR → NV12 端到端推理流程。
