# 2026-10-05 Quest 3 播放器迁移：历史性能归档

本轮仅复核历史资料和官方设备文档，没有重新跑 PC 基准，也没有在 Quest 3 上运行模型。PC 数字主要来自 RTX 5060 Ti 16 GB。处理吞吐、视频实际帧率、头显刷新率分别统计；PC 独显 VRAM 不能换算为 Quest 3 的共享 RAM。

| 功能 | 历史 PC 能力 | 显存证据与 Quest 判断 |
|---|---|---|
| 原片播放、投影、字幕、SI 音轨 | 按片源 FPS；没有独立处理最高 FPS 测试。SI 预混 M4A 复制原视频样本 | Quest 首批。优先硬解码、SBS/TB/180/360、字幕、音轨、seek 与同步；内存增量未测 |
| 轻量光照/色彩/HDR 观感 | PC CUDA 像素核；没有独立最高 FPS | Quest 首批 shader；全帧缓冲内存未测 |
| RVM Green/Alpha | 8K、1024 输入、静态 TRT：实时 alpha 处理约 77 FPS，离线 alpha 75.62、green 75.46 FPS；早期 CUDA FP16 默认约 43.13 FPS | README 的 ≥6 GB 是 PC 部署建议，非峰值；旧卡死测试 1619→4145 MiB 是异常，不能当正常需求。机内暂缓，PC 处理后 Quest 播放 |
| DA3 2D→3D/VR | 1080p 源 GPU 离线：flat3d 149、fisheye 75、hequirect 71 FPS；后两者输出 8192×4096。HD 1036 离线约 16 FPS | README 普通档 ≥6 GB 是建议，峰值未测。优先 PC 生成 SBS，机内只考虑另做小模型 POC |
| RM 去马赛克 | 1080p 单区域处理核心约 193 FPS；8K 双区域加入 VR 超采样后核心约 106 FPS；1080p 离线含编码/混音约 114 FPS | 峰值未测；7 帧窗 + ROI。第二批可试单 ROI 机内 POC，需验证 Android 推理算子 |
| 人脸美颜 | 1080p 双脸、GPEN256 隔帧关键点约 37.27 FPS；8K VR 稳态核心约 58.97 FPS，但困难双脸片段仅约 25.14 FPS | 峰值未测。先做简单 shader 美颜，多模型链后置 |
| MatAnyone2 + SAM3 | 4K 600 帧离线约 18.01 FPS；低显存短片约 13.5 FPS | README 建议约 ≥15 GB PC 显存；历史 SAM3 预处理曾超过 10 GB。保留 PC 离线 |
| NVDS 深度稳定 | 512×288 单段约 6.8 FPS，DA3+NVDS+渲染端到端约 4.2 FPS | 端到端约 11.5 GB；672×384 曾有 12.6 GB 稳态/12.9 GB 峰值。不迁机内 |
| RTX VSR / TrueHDR | 4K VR→8K Ultra 约 23–24 FPS；Medium 短测 43.4；TrueHDR 叠加后约 15.6 FPS；2D 1x 短测 75.3 FPS | 峰值未测。NGX/RTX 无法原样在 Snapdragon 上运行；保留 PC 处理或另做空间锐化 |
| DLSS5 NR | PC 4K VR 真 seek 端到端约 31.9 FPS；4K 2D 约 28.3；8K 单阶段约 7.9 | 峰值未测；不排入 Quest 机内首批 |

数据出处：RVM 见 summary/summary_20260520_RVM_INPUT_SIZE_DOWNSAMPLE_FPS_CN.md、summary/summary_20260522_OFFLINE_RVM_THROUGHPUT_GAP_RESOLUTION_CN.md；DA3 见 prompt/HANDOVER_20260615.md、summary/summary_20260616_DA3_INPUT_RESOLUTION_EXPERIMENT_CN.md；RM 见 summary/summary_20260625_REALTIME_MOSAIC_RESTORATION_RM_AND_FPS_OPT_CN.md、prompt/HANDOVER_20260808.md；美颜见 prompt/HANDOVER_20260802.md；MatAnyone2 见 prompt/HANDOVER_20260527.md 和 prompt/HANDOVER_20260518.md；NVDS 见 prompt/HANDOVER_20260620.md；VSR 见 prompt/HANDOVER_20260720.md、summary/summary_20260911_VSR_NATIVE_AND_6K_CN.md、summary/summary_20260911_TRUEHDR_OFFLINE_SUPERRES_CN.md；NR 见 prompt/HANDOVER_20260913.md；SI 见 prompt/HANDOVER_20261003.md。

Meta 官方：Quest 3 为 XR2 Gen 2、8 GB 共享 RAM，应用目标至少 72 Hz、推荐 90 Hz。媒体指南对 180° SBS 给出常见 7680×3840/60、最高 8192×4096/60 的硬解码指导；这不是本项目播放器真机达标证明。
- https://developers.meta.com/vr/resources/device-optimization-comparison/
- https://developers.meta.com/vr/documentation/android-apps/media-requirements/
- https://docs.qualcomm.com/bundle/publicresource/87-73689-1_REV_A_Snapdragon_XR2_Gen_2_Platform_Product_Brief.pdf

迁移顺序：先完成 Quest 硬解码播放器 + 投影/双眼 + 字幕/SI + 轻量显示 shader；RVM、DA3、RM、美颜暂由 PC 处理，Quest 播放结果。若必须完全脱离 PC，先试 RM 单 ROI，再试小型深度模型；RVM 需单独验证机内推理、合成、解码显示和热稳定。MatAnyone2、NVDS、RTX VSR、DLSS5 不适合作为首批机内实时任务。Alpha 是六块 mask 专有布局，Quest 端需解包或另定颜色+mask 协议。

后续共同基准：同素材记录 PC 各模式的启动前、稳态和峰值 VRAM 与 30 分钟持续处理 FPS；Quest 记录进程 PSS、视频实际 FPS、XR GPU 帧时、掉帧、热降频、音画偏差及反复 seek。现有大多数功能没有同口径显存峰值，不能用模型文件大小填补。
