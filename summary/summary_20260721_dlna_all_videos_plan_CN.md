# DLNA“全部视频”功能开发计划（2026-07-21）

## 目标

1. 设置页高度与首页保持一致，避免切换到设置时窗口高度变化。
2. 在设置页 DLNA 服务器区域增加“DLNA 首页显示‘全部视频’”开关，默认关闭并持久化。
3. 服务器启动时读取当前 UI 语种；开关开启时扫描所有视频目录，将支持的视频按名称排序缓存到内存。
4. DLNA 首页末尾显示对应语种的“全部视频”；进入后显示视频文件名目录，继续进入显示源文件及已启用的实时播放入口（包括 VR rename）。

## 实施步骤

1. 检查并统一设置页与首页的尺寸调整逻辑，移除设置页独立高度差异。
2. 扩展 `ui.settings.Settings` 默认值、环境变量导出和设置页控件/翻译文本。
3. 在 DLNA 内容目录模块增加启动期索引对象：遍历 `VIDEO_DIRS`、过滤 `VIDEO_EXTS`、按显示名称排序、记录安全路径与 VR 显示名。
4. 增加“全部视频”根容器及文件名容器的 ObjectID 编解码、DIDL 生成和 Browse 分发；复用现有源文件、直播、SI/RM/VR rename 逻辑。
5. 在服务器启动流程中按开关构建索引，并在配置/目录变化时清理相关缓存；关闭开关时不扫描。
6. 增加单元测试覆盖：默认关闭、排序/过滤、多根目录安全性、根目录末尾显示、文件名容器内容和语言标题。
7. 运行语法检查与测试，记录结果并生成交接文档。

## 验收标准

- 设置页与首页切换不改变窗口高度。
- 新开关默认未选中，三种 UI 语言均有正确文案。
- 开启后服务器启动日志可确认索引完成；DLNA 首页最后出现本地化“全部视频”。
- “全部视频”下一级只有文件名目录；再进入后可见源文件和当前配置启用的实时入口，VR 文件显示 rename 后名称。
- 关闭开关时保持原有 DLNA 行为且不执行全量扫描。
